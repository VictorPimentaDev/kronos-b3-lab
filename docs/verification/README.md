# Verification evidence · 2026-11-06

The real `amazon/chronos-t5-tiny` checkpoint was downloaded and run on CPU on
synthetic fixtures with the command below. This is a compatibility smoke test of
one origin and three targets, **not a meaningful model-quality benchmark**.

```sh
b3-lab run --models seasonal-naive,random-walk,chronos --context 177 --horizon 3 --out runs/chronos-smoke
```

Exit code: 0. `chronos-manifest.json` records versions, input hashes and configuration;
`chronos-metrics.csv` is the unedited output. CI verifies adapter call contracts
using test doubles. Kronos and TimesFM weights were run later, on the same date: see
[`smoke-2026-11-06/`](smoke-2026-11-06) and the [model smoke guide](../model-smoke.md).

The ordinary suite passed 32 tests, including the Streamlit AppTest, and the wheel
and sdist built successfully. The README plot is separately generated by:

```sh
b3-lab run --horizon 3 --out runs/readme
```

The Streamlit screenshot is captured from the real local app using the same
synthetic fixture. `social-preview.png` is a repository cover image, not a result
chart; it can be uploaded in GitHub repository Settings → Social preview.

The optional Yahoo adapter also fetched WEGE3.SA and ^BVSP for 2024-01-01
through 2025-01-01 (exclusive) and the aligned-pair CLI run completed successfully.
Downloaded market data remain ignored under `data/`; they are not redistributed.
