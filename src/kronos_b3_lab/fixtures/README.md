# Synthetic fixture provenance

`asset.csv` and `ibov.csv` are **fictional** OHLCV paths generated by
`scripts/generate_fixtures.py`, seed `20261106`, on 2026-11-06. There are 180
weekday observations starting 2025-01-02. Weekdays are **not** a B3 exchange
calendar: Brazilian holidays were deliberately not modeled. These files are
software fixtures, not WEGE3, not historical IBOV, and not model performance.

Prices use correlated lognormal shocks, synthetic opening gaps and nonnegative
volume. No client data, scraped prices or third-party datasets are included.
`python scripts/generate_fixtures.py` regenerates the CSVs in a development install.
